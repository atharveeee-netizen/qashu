PNA — Propagated Noise Absorption

qc/mitigation qc/noise

Propagated Noise Absorption (PNA) mitigates gate noise by rewriting the observable rather than the circuit. It propagates the inverse of each layer’s learned Pauli-Lindblad noise forward through the circuit and absorbs it into the measurement observable, producing a noise mitigating observable O~.

Core idea

  • Circuit: unchanged
  • Observable: rewritten from O to O~

Measuring O~ on the noisy circuit gives the same expectation value as measuring O on the ideal (noiseless) circuit.

This works because Pauli noise channels compose and propagate efficiently through Clifford gates via the commutation rules from section 1.2.

Boxing strategy

PNA uses inject_noise_strategy="uniform_modification". All layers share a global noise_scales slot, set to 0 — this leaves the sampled circuits untouched while still associating each layer with its learned model so the model can be propagated into the observable.

measure_annotations="all" adds both Twirl and ChangeBasis to the measurement box, because O~ will contain non-Z terms that require measuring in different bases.

Four-step PNA workflow

1. Box the circuit

2. Learn the noise

3. Compute the noise mitigating observable O~

The function propagates the inverse of each layer’s noise channel through the circuit using Clifford conjugation, then folds those corrections into O to produce O~.

Truncation: max_err_terms and max_obs_terms keep only the dominant terms so O~ remains measurable. More terms → better accuracy, but more measurement bases required.

4. Run with Executor

What O~ looks like

For a ZZ observable on the middle pair of a 10-qubit chain:

  • The original ZZ term at magnitude 1 remains the dominant term (slightly amplified above 1)
  • Many new Pauli terms appear — these are the anti-noise corrections PNA propagated from the learned noise model
  • Results vary by QPU and calibration date
